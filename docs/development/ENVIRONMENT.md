# 环境与实验室

## 当前引导环境

必须：Git、可用的精确稳定Rust（支持edition2024）、Cargo、rustfmt、Clippy、Python3.10+、Bash。版本由现场doctor输出记录，不预填不存在的版本。

Mac日常编辑与快速检查；Linux承担协议网络、资源和后续故障注入的基线。初始化CLI不需要数据库、Node、Docker、SIP账号、音频设备或外线服务。没有某个环境不自动安装；说明缺什么。

## 第00章尚需独立完成的实验室项

| 项目 | 真正完成的含义 | 未完成时 |
|---|---|---|
| SIPp或独立协议端 | 确认版本，在受控地址实际发/收一条协议消息 | AC-00-03保留待办 |
| 真实SIP客户端 | 明确版本、设备与本地测试拓扑，能使用音频设备 | 不能用单元测试冒充 |
| 抓包权限 | 对受控测试端保存实际抓包，脱敏并记录校验值 | 不生成假PCAP |
| 独立合法样例 | 不由YakYak序列化器产生；标注来源与字节 | 不能仅把网上文本存成文件就说实网验收完成 |
| Linux检查 | 同一commit同一check.sh真实运行 | 配置文件存在不等于执行 |

此时YakYak不需要响应SIP；可以在独立、用户控制的测试端之间验证工具链。不得使用上游默认公网探针或随机公网服务器。首选loopback或隔离局域网，显式测试号码和端口；以后付费线路需另行授权。

后续Linux网络故障注入、NAT、TURN等在对应章节搭建，初始化不预建复杂Docker Compose或Kubernetes。记录工具版本与拓扑比“装过软件”更重要。

## 工具不足的处理

完成文档和可运行检查，将受限目标标blocked并写解除条件。不得执行未知远端安装脚本、修改防火墙、提高全局权限或改用户默认Rust配置来绕过环境问题。

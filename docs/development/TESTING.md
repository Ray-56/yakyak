# 测试与验收规则

具体125项目标见roadmap；本文件描述如何提交可信证据。

## 测试层级

单元/属性验证纯逻辑；网络集成验证实际I/O；端到端验证独立终端的外部行为；故障测试验证丢包、重复、取消、资源上限与退出。按目标选择，不把同一个单元测试重复命名成三层验证。

初始化只实现bootstrap组。network/e2e未实现时返回非零NOT_IMPLEMENTED，不能静默跳过。在引入这些组的章节再写真实测试，不预建125个空测试。

Cargo集成测试使用明确入口，如tests/bootstrap.rs；后续tests/sip_parser.rs等按需增加。子目录辅助模块必须被入口引用，不假设任意深层.rs都自动被Cargo运行。用例名称、完整过滤器和`--list`结果记录在报告，实际执行数量必须非零。

## 用例的四个问题

正常输入是否得到正确结果？无效或失败输入是否受控？结束时任务/端口/状态是否按设计释放？第三方能否在声明环境复现？

解析器无端口可写N/A；状态机用可控制时钟，不能靠长sleep凑结果；同时保留真实Socket测试证明动作真的执行。媒体测试验证双向内容或解码，不只检查包数、active布尔值和日志。

## 失败不能被吞掉

脚本使用严格退出码与pipefail；环境缺失区分failed和not_run，但二者都不能给功能绿色通过。测试重试用于诊断时保留每次结果，不只截取最终成功一轮。失败阈值先约定，不在看到结果后修改。

## 报告和原始产物

小型脱敏Markdown在docs/acceptance/chXX/AC-XX-YY.md；同一目标复验可用带日期的子报告，保留旧证据和失效原因。原始文件在artifacts/chXX/<commit>/<scenario>/；记录SHA-256、测试端版本、网络拓扑、随机seed、媒体参数与时钟方式。

公开仓库不提交真实号码/凭据/Authorization/录音。synthetic fixture须标注合成，不能冒充独立真实抓包。抓包和音频需要场景授权。README中的支持矩阵与报告一致。

## 初始化额外自检

至少4个真实CLI进程用例；Python数据工具正反向测试；错误AC、无证据passed、生成漂移必须拒绝。负面试验在临时副本进行，不能污染用户源目录。

自动校验只证明结构和引用，无法证明人类真的审阅、录音内容正确或测试环境描述真实；这些仍需用户确认。

# 当前不支持的功能

记录日期：2026-10-21（Asia/Shanghai）。适用于当前重写后的活跃代码；旧实现的历史能力不计入当前支持情况。

范围依据为用户已确认的 [SCOPE v1.0](roadmap/SCOPE.md)。本表汇总当前能力和边界，不新增或删减需求；逐项验收状态以 [progress.json](roadmap/progress.json) 为准，可阅读生成的[进度视图](roadmap/PROGRESS.md)。

当前 [CLI 入口](../src/main.rs)仅处理帮助、版本和“通信服务尚未实现”的提示，不启动网络服务。以下“尚未实现”是当前阶段的功能状态；“范围排除”表示 SCOPE v1.0 明确未纳入的能力。

## SCOPE v1.0 明确排除

以下项目的范围依据均为 [SCOPE 的明确排除及功能对齐矩阵](roadmap/SCOPE.md)，没有为其分配实现 AC。若以后调整范围，应先按仓库约定确认需求并记录 ADR。

| 能力 | 当前情况 | 限制与边界 |
|---|---|---|
| AI 应用与模型适配 | 范围排除 | AI Agent、LLM、ASR、TTS、实时/离线转写、通话总结、知识库、模型工具调用、AI 质检、模型服务协议适配全部排除；普通录音、双向 PCM、DTMF、固定提示音和音频电平检测保留。 |
| 商业扩展产品 | 范围排除 | 商业计费结算、语音批发平台、完整商业联络中心、商业可视化流程设计器、CRM/WFM 等排除；基础 PBX 应用与授权监督保留。 |
| 额外协议、硬件与电话/聊天产品 | 范围排除 | T.38 传真、SS7/模拟硬件、移动推送电话、完整聊天产品排除；限定的 SIP MESSAGE 和订阅通知保留。 |
| 视频处理扩展 | 范围排除 | 视频转码、多人混屏、完整 SFU 排除；两端共同编码的视频透传保留。 |
| 进行中通话无损跨机迁移 | 范围排除 | 有限多节点、必要状态同步和新呼叫恢复保留，不承诺进行中通话无损接管。 |

## 验证限制与更新方式

- 工程、文档、CI 或外部 SIPp/真实客户端的准备结果，不能作为 YakYak 已支持通信功能的证据；当前表格没有声明任何通信能力通过验收。
- 后续只根据对应能力的可复现命令、实际结果、证据与人工验收更新支持情况；部分能力通过时，应细化其支持边界，不把整个能力组直接记为支持。
- AC 状态继续只改 progress.json；本表保持与范围和已验收能力一致。实验环境与缺陷的具体问题、解除条件另见[已知问题清单](work/KNOWN_ISSUES.md)。

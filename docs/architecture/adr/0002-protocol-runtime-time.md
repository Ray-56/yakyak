# ADR-0002：协议状态、I/O动作与时间分离

状态：Proposed（待用户评审）。关联：AC-00-04。

## 决定

协议层接受消息、定时器到期和明确命令，产生发送、计时器设置/取消、通知和资源动作。运行时执行Socket与任务操作，并将结果作为事件回送。初始化仅记录边界，不实现事务枚举和接口。

事务/Dialog的计时采用单调时间；日志/报告使用墙上时间；测试可推进虚拟时钟。不得用真实长sleep使协议测试缓慢且不稳定。

## 例子

UDP请求丢失 → 某事务timer到期 → 协议层产生重传动作 → 运行时实际发送缓存消息 → 独立网络测试端观察到重传。
单元测试证明动作正确；网络集成证明动作被执行。两者不能相互替代。

## 结束与资源

停止业务、停止媒体、协议必要状态保留分别处理。显式取消要唤醒无流量时的接收任务并等待退出；事务为处理重传保留状态时不要求瞬间归零。只有running布尔值改变不算完成关闭。

## 待评审

ID职责与消息所有权、时钟注入方式、动作执行失败语义、谁负责取消并join。具体Rust接口在相应章节由用户设计，当前不预写核心代码。

# ADR-0003：要求、状态、证据分离

状态：Accepted（2026-10-21，用户在本会话明确确认）。关联：AC-00-05、INIT-05。

目标原文只在targets.json；状态只在progress.json；分章、总览和进度表生成；真实报告另存。原因是避免同一个AC在多个Markdown里状态不一致。

passed需要真实可达commit、可复现命令、实际结果、现有证据报告、日期和人工确认。自动工具校验字段与文件存在，不能证明测试真实或替代人工决定。

原始产物放忽略目录或授权私有存储，公开仓库只放脱敏摘要和可复验记录。原规划原文保留在交接包，仓库存档记录其哈希和转换规则。

代价：增加Python标准库文档工具；不引入通信运行依赖。后续若迁移到Rust xtask，应保留数据格式、负面测试和确定性生成行为。

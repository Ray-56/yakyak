# ADR-0001：单crate起步，逐步长出内核

状态：Proposed（待用户确认）。关联：INIT-07、AC-00-04。

## 决定

初始化只有std-only CLI壳与测试。后续解析、事务、运行时、媒体按实际章节增加模块；不预建workspace和27套空模块。要拆crate时先证明职责稳定、复用需求和测试边界。

## 原因

用户要亲自理解通信行为。过早设计大目录、依赖和服务，容易掩盖尚未成立的通话主链路。

## 替代与后果

一次建立完整分层workspace看似规整，但前期接口大多只是猜测。单crate不等于允许循环职责和全局共享状态；模块边界仍需明确。引擎稳定后允许重审，并非永远禁止拆分。

### 2. 在终端 A 启动被叫

```bash

  -t u1 -i 127.0.0.1 -p 15061 -bind_local \

  -trace_err -error_file uas-errors.log

printf '%s\n' "$yakyak_uas_exit" > uas-exit-code.txt

```

### 3. 配置并开始这一次 Wireshark 抓包

Capture → Options → Input 只勾选 `lo0`，在 `Capture filter for selected interfaces` 捕获过滤器栏填下式；顶部显示过滤栏保持空白：

```text
udp and host 127.0.0.1 and (port 15060 or port 15061)
```

Output 保持单文件 `pcapng`，不启用自动创建下一文件。Options → Stop capture automatically after 分别勾选时间与大小两行，设为 `60 seconds` 和 `10 megabytes`，其余停止条件不勾选。Wireshark 此处为十进制单位，10 megabytes 约 9.54 MiB，低于计划的 10 MiB；这是停止阈值，可能多写最后一包。上述设置完成后，由用户点击 Start，只捕获该受控场景。

### 4. 在终端 B 发起一次主叫

先 `cd` 进入终端 A 的 `pwd` 所打印的完整目录，再执行：

```bash
/opt/homebrew/bin/sipp 127.0.0.1:15061 -sn uac \
  -t u1 -i 127.0.0.1 -p 15060 -bind_local \
  -ci 127.0.0.1 -cp 18888 -mi 127.0.0.1 \
  -m 1 -l 1 -r 1 -d 1000 -timeout 20s -timeout_error \
  -trace_msg -message_file uac-messages.log \
  -trace_err -error_file uac-errors.log
yakyak_uac_exit=$?
printf '%s\n' "$yakyak_uac_exit" > uac-exit-code.txt
cat uac-exit-code.txt
```

`-r 1` 指定每秒一次的发起速率，`-m 1` 使总次数仍为一次。`-d 1000` 让内置主叫在 ACK 后等待约一秒再发 BYE。主叫全局超时为 20 秒，`-timeout_error` 确保超时不冒充成功。正常两端都会自动退出，被叫还有内置四秒 timewait；无需通过 q 或 Ctrl-C 制造结束。
